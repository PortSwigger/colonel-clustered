Colonel Clustered analyzes the content of HTTP responses and groups them into clusters based on textual or structural similarity. It is designed to surface outliers and distinct response groups from large sets of requests, such as those produced by fuzzing runs, going beyond indirect measures like status codes and response sizes.

Features

  • Content-aware tokenization that adapts strategy based on the Content-Type header, handling HTML (tag-stripped 5-grams), JSON (key path extraction), plain text (5-grams), and binary (5-byte n-grams) responses differently.
  • Fast Scan mode using a DBSCAN-based algorithm with automatic epsilon tuning via the Kneedle algorithm, triggered automatically when responses are submitted.
  • Deep Analysis mode using hierarchical clustering with average linkage and a full Jaccard distance similarity matrix, available on demand for more granular results.
  • Pre-grouping pass that hashes token sets to batch identical responses before clustering, reducing the computational load on the core algorithms.
  • Automatic outlier consolidation that collects all singleton clusters into a single dedicated Outliers group in the UI for easy review.
  • Digit sanitization during tokenization to prevent minor numeric variations (such as IDs) in templated responses from producing false splits between clusters.

Usage

  1. Navigate to any tool containing request/response items (such as Intruder results or Proxy history).
  2. Select one or more items, right-click, and choose Send to Colonel Clustered.
  3. Switch to the Col. Clustered tab; a Fast Scan will begin automatically and a progress bar will indicate analysis status.
  4. Review the resulting cluster groups in the UI. Responses that did not fit any cluster are consolidated under the Outliers group.
  5. To run a more thorough analysis on the same dataset, click the Deep Analysis button. Note that this algorithm scales as O(n³) and is best suited for smaller response sets.
  6. Click any cluster group to inspect the individual responses it contains and compare their content.
